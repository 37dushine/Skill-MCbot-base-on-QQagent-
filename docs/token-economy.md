# 省 token 的设计

> 目标不是"少花一点"，而是：**你不主动找它，它就一分钱不花。**

## 原则

把"能用 if 描述的事"全部从模型手里拿走。模型只保留一件事：**理解人话要干什么**。

| 事情 | import/触发 | 谁来做 | token |
|---|---|---|---|
| 发现局域网世界并加入 | 组播包 | 确定性代码 | 0 |
| 掉线重连 | `end` 事件 | 确定性代码 | 0 |
| 自己玩（走动、张望、躲怪、捡东西…） | 12 秒定时器 | 确定性代码 | 0 |
| 游戏内 `!命令` | 正则 | 确定性代码 | 0 |
| 上下线 / 死亡通知 | 生命周期事件 | 确定性代码 | 0 |
| 游戏聊天镜像 | 聊天事件 | 确定性代码 | 0 |
| 游戏聊天（没叫名字） | 名字匹配失败 | 直接丢弃 | 0 |
| 游戏聊天（叫了名字） | 名字匹配成功 | 注入宿主，由档位决定 | 按需 |
| QQ 群消息 | 宿主原生管线 | 宿主档位判定 | 按需 |
| 执行"去挖那块石头" | 模型决定 | 模型 + 工具 | 花 |

## 自主游玩的行为池

权重是**相对值**（总权重 71 左右，随场景变化），不是百分比。

| 行为 | id | 触发条件 | 权重 | 说明 |
|---|---|---|---|---|
| 到处走走 | `wander` | 总是 | 34 | 在 `exploreRange` 内随机挑方向走 |
| 四处张望 | `look` | 总是 | 20 | 原地转头，最像"在发呆" |
| 小跑一段 | `sprint` | 总是 | 11 | 冲刺 1.6 秒 |
| 原地蹦跶 | `jump` | 总是 | 6 | 跳一下 |
| 凑近看玩家 | `visit` | 有玩家且 **>8 格**、≤40 格 | 26 | 走到 4 格停住，不贴脸 |
| 去捡东西 | `pickup` | 16 格内有 `item` 实体 | 26 | 走到 1 格内（捡起是自动的） |
| 观察动物 | `watch` | 22 格内有 animal / water_creature | 16 | 走到 3 格 |
| 探索村庄营地 | `site` | 32 格内有钟/堆肥桶/工作台/熔炉/营火/灯笼/箱子/床/火把 | 18 | 走到 4 格 |
| 砍一块木头 | `gather` | `autoGather` 开 + 24 格内有原木 | 30 | 走到 2 格，9 秒后若还在 4.5 格内才挖 |
| **躲开怪物** | `flee` | 24 格内有敌对生物 | **短路** | 只剩这一项，反向跑 26 格 |

举例：空场景下 `wander` 概率 34/71 ≈ 48%；村庄 + 旁边有人 + 地上有东西时，总权重变成 34+20+11+6+26+26+18 = 141，`wander` 降到 24%——**处境越丰富，越倾向去互动**。

### 一次 tick 的成本

- 定时器每 12 秒一次；
- 每次只做几次数组遍历 + 一次随机（几百个实体最多几微秒）；
- **不产生任何网络请求、不产生任何 token**；
- `busyUntil` 防止动作过密（1500 / 3000 毫秒冷却），不会每 tick 都下寻路。

## 模型侧的四个优化

1. **`mc_observe` 一次给全**：位置、血量、食物、玩家（带距离）、威胁（24 格内聚合）、背包摘要、手持、上次异常、最近见闻，**一次工具调用**。提示词里明确要求"不要反复查"，避免 3~5 次连环调用。
2. **移动异步**：`mc_move` 下达即返回，不让模型挂着等寻路走完（等 = 会话被占住 + 上下文膨胀）。
3. **工具描述压到两三句**：8 个工具的描述都很短，`mc_observe` 无参数，`mc_inventory` 的描述直接写"其实 observe 已带，只有要专门操作时才用"。
4. **提示词只有一段**：`prompt.sections` 里只有一个 `mc-bot-note`（约 400 字），不是每个工具一段。

## 和"不加设计"的对比

假设一个下午 3 小时，主机在玩，分身陪着：

| 做法 | 模型调用次数（估） |
|---|---|
| 每个 tick 都问模型"现在该干嘛"（12 秒一次） | 900 次 |
| 每条游戏聊天都送进模型 | 数百次 |
| **本技能（默认设置）** | **0 次**，直到你叫它 |

你主动说一句、或游戏里叫一次名字，才产生一次调用。挂机一整天，成本是 0。

## 想更省 / 想更热闹

| 诉求 | 调整 |
|---|---|
| 更省（几乎不耗资源） | `exploreIntervalSec` 调 60；关 `autoChatter` |
| 更活泼 | `exploreIntervalSec` 调 8；`exploreRange` 调 24 |
| 让它别自己玩，只当工具人 | `autoExplore` 关 |
| 群里想看到游戏实况 | 开 `relayToQQ`（**仍然零 token**，只是消息变多） |
