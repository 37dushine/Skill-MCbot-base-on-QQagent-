# 指令与工具

## 一、游戏内 `!` 命令（零 token、秒回）

在 Minecraft 聊天框直接发，**不需要叫名字**，谁都能用。半角 `!` 和全角 `！` 都行，前缀后的空格会被忽略。

| 命令 | 别称 | 效果 | 它会回什么 |
|---|---|---|---|
| `!来` | `!come` `!过来` `!来这` `!来我这` `!过来这` | 走到发命令的人身边 | `Steve，这就过去` / `过不去：看不到这个玩家…` |
| `!跟随 [名字]` | `!follow` `!跟着` `!跟上` | 持续跟随某人，保持约 3 格；不填名字 = 跟发命令的人 | `好，我跟着 Steve` |
| `!停` | `!stop` `!停下` `!别动` `!站住` | 立刻停下 + **暂停自主游玩** | `好的，我停了` |
| `!状态` | `!status` `!在哪` `!位置` `!坐标` | 报坐标和血量 | `我在 (123, 64, -45)，血 20/20` |
| `!帮助` | `!help` `!命令` `!指令` | 列命令 | `可用：!来 \| !跟随 [名字] \| !停 \| !状态` |
| 其它 | — | 没听懂 | `没听懂。可用：!来 / !跟随 / !停 / !状态` |

> `!停` 之后自主游玩是**暂停**状态，发 `!来` 或在群里说「继续自己玩」即可恢复（对应的工具是 `mc_move` 的 `wander`）。

## 二、游戏里叫它的名字

只要聊天内容里出现它的名字（`username` 设置 / 当前 `bot.username` / 人设名 / 人设昵称，任一命中，不区分大小写），这条消息就会以「被 @」的口径注入绑定的 QQ 群，由宿主决定要不要唤醒模型。

```
小明 过来一下
小明在吗
喂 小明 帮我看下附近有怪吗
```

**没叫名字的聊天默认不处理**（`chatMonitor: mentions`），既不入库也不花 token。想让所有聊天都进群，开「游戏聊天镜像到 QQ 群」。

## 三、QQ 群里说人话

### 上下线

- 「进游戏」「来 MC 里」「上线」
- 「连 mc.example.com」「去 1.2.3.4:25565 那个服」
- 「下线吧」「先出来」

### 移动

- 「去 100 64 200」「到坐标 100 64 200 来」
- 「到我这儿来」「过来一下」
- 「跟着 Steve」「别跟着了」「停下」「继续自己玩」

### 干活

- 「挖掉 120 65 300 那块石头」
- 「把石头放在 121 64 300」
- 「背包里有什么」「把手上的东西丢掉」「把镐子拿在手上」

### 说话与打听

- 「在游戏里说一句大家好」
- 「你现在在哪」「你刚才在干嘛」「看到什么了」「附近有几个玩家」「有怪吗」

> 记住：**在群里说话 ≠ 游戏里能听见**。要让游戏里的人看到，必须让它用 `mc_chat`（「在游戏里说 xxx」）。

## 四、模型可调用的工具

给模型看的完整清单。所有工具失败时返回 `{ content: '错误：…', isError: true }`，**不抛异常**，不会打断会话。

### `mc_control`

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `action` | `status` / `connect` / `disconnect` | ✓ | 动作 |
| `host` | string | | 本次连接的地址（不含端口） |
| `port` | number | | 本次连接的端口 |
| `version` | string | | 本次连接的版本，空 = 自动探测 |

`connect` 不填地址时用设置里的 `host:port`。已经在线时返回「已在线」而不是重连。

### `mc_observe`

无参数。一次返回：

```
在线：小明 @ 127.0.0.1:51234（1.21.4，局域网世界）
位置：(123, 64, -45) | 血量 20/20 | 食物 20/20 | 状态：到处走走
玩家(2)：Steve(6格)、Alex(18格)
威胁：zombie×2（24格内）
背包(4格)：oak_log×3、stone×12
手持：stone
最近见闻：发现工作台，像是有人来过，过去看看；砍了 橡木
```

离线时返回错误并提示怎么上线（或「正在连接…」）。

### `mc_chat`

| 参数 | 类型 | 必填 |
|---|---|---|
| `text` | string | ✓ |

发出后会在存档里留痕（`[MC] xxx`），下一轮它才记得自己说过什么。上限 200 字（游戏聊天本身约 256）。

### `mc_cmd`

| 参数 | 类型 | 必填 |
|---|---|---|
| `command` | string | ✓ |

带不带 `/` 都行。权限不足会被服务器拒绝，**结果不会自动回传**——重要操作要用 `mc_observe` 验证。

### `mc_move`

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `mode` | `goto` / `come` / `follow` / `stop` / `wander` | ✓ | 移动方式 |
| `x` `y` `z` | number | goto 必填 | 目标坐标 |
| `player` | string | | `come` 可留空（最近的玩家）；`follow` 必填 |

**异步**：下达即返回，不挂起会话等寻路走完。坐标会被钳制在 ±1e7。

### `mc_dig`

| 参数 | 类型 | 必填 |
|---|---|---|
| `x` `y` `z` | number | ✓ |

会先检查：是不是空气（拒绝）、是不是基岩/不可破坏（拒绝）。`dig` 最长等 30 秒，超时返回错误而不是卡住会话。

### `mc_place`

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x` `y` `z` | number | ✓ | 目标必须**是空气** |
| `item` | string | | 背包里的方块名，模糊匹配；留空 = 背包里第一个像方块的物品 |

需要相邻有实体方块做贴放参照，悬空会拒绝。

### `mc_inventory`

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `action` | `list` / `equip` / `drop` | ✓ | |
| `item` | string | equip/drop 必填 | 模糊匹配 |

`list` 返回手持 + 按名字聚合的数量列表；`drop` 丢**一整叠**。

## 五、常见错误信息对照

| 返回 | 原因 | 怎么办 |
|---|---|---|
| `分身不在线，先 mc_control connect` | 没连上 | 先上线；单机记得「对局域网开放」 |
| `寻路模块不可用` | `mineflayer-pathfinder` 没装或被裁剪 | 在 app 根 `npm install mineflayer-pathfinder` |
| `看不到这个玩家（不在视野里或名字不对）` | 距离超出实体加载范围，或名字打错 | 让对方走近，或用 `goto` 坐标 |
| `(x, y, z) 是空气，没东西可挖` | 坐标算错了 | 先 `mc_observe` 确认坐标 |
| `(x, y, z) 周围没有可以贴着放的实体方块` | 悬空放置 | 换个位置，或先垫一块 |
| `背包里没有「xxx」` | 名字不对/没有 | `mc_inventory list` 看实际名字 |
| `挖掘超时（30 秒）` | 生存模式徒手挖硬方块，或距离太远 | 先靠近、换工具 |
